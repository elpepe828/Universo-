                                          # Universe Simulator

                                          Este es un simulador básico del universo desarrollado en Android. Muestra un planeta que se mueve en un fondo estrellado.

                                          ## Características

                                          • Un planeta que se mueve verticalmente.
                                          • Fondo con estrellas.

                                          ## Requisitos

                                          • Android Studio
                                          • SDK de Android

                                          1. Clona este repositorio:
                                             

                                             2. Abre el proyecto en Android Studio.
                                             3. Ejecuta la aplicación en un dispositivo o emulador.
